## Oponent
Ing. Pavel Jedlička

## Shrnutí projektu
Funkční edukativní model vyrobený z HT potrubí a 3D tištěných PET dílů. Model simuluje přenos energie pomocí systému dvou motorů (motor-generátor) v uzavřené "strojní kleci". Dále zprostředkovává měrění výstupu a popisuje další změny při zpracovávání elektrické energie.
